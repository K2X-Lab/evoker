# LinkedIn launch post

Evoker is now in public beta.

I built it because I wanted React interfaces with sharp panels, bold typography and layered motion.

The beta includes buttons, menus, dialogs, form controls and larger components such as quest briefs, party panels and code blocks. It is open source under MIT, with keyboard support and reduced-motion settings.

A dedicated motion library and more components are coming soon.

Try the playground and docs:
https://k2x-lab.github.io/evoker/

Install the beta:
`npm install @kartikeyak/evoker@beta`

npm:
https://www.npmjs.com/package/@kartikeyak/evoker

Source:
https://github.com/K2X-Lab/evoker

If you try it, let me know which components you would use and what needs work.
