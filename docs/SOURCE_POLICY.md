# Source and distribution policy

Evoker is an angular UI component library inspired by Persona 3 Reload. Public packages contain original TypeScript, React components, CSS geometry and documentation. Applications supply their own content and data.

Artwork, fonts, data tables, keys, decoder tooling, research evidence and conversation transcripts from that title remain private local material. They are excluded from Git and package archives. No game installation is needed to build or use the library.

Reference research informs composition principles such as independent decorative layers, selection indicators, text and motion. This does not establish exact game runtime fidelity. Native execution, material playback and final screen composition have not been verified.

Evoker is not affiliated with the game's creators. Git ignore rules prevent routine staging; they do not encrypt local files or prevent deliberate force-add operations. npm packages allow only package metadata and built library outputs.
